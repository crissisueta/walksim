# walksim procedural room templates
#
# Each section defines one room template. A Room references its template by
# index (templateId) into this list. Dimensions are in metres. socket controls
# which doorway category the room exposes, weight controls how often the
# generator picks the template (weight=0 means never, e.g. the entrance), and
# role tags special templates (entrance, normal, stairs, utility).
# Keep width and depth multiples of 5 m so every socket centre stays on the
# 2.5 m building grid for predictable plans.
#
# Optional windows use: window=side,offset,width,bottom,height
# side is north, south, east, or west; offset is measured from the middle of
# that wall. Windows only appear where that wall segment remains exterior.
